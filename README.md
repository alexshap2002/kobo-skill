# Kobo для Claude Code

Плагін для працівників **«Будь вільний»** і **«Є добро»**. З ним Claude Code працює з вашим акаунтом на
[eu.kobotoolbox.org](https://eu.kobotoolbox.org) звичайною мовою:

- створює й змінює форми;
- розгортає форми;
- вивантажує відповіді в Excel;
- робить звіти й дашборди;
- виправляє значення у відповідях;
- дає доступ колегам.

Плагін сам дотримується правил організації:

- **Копія перед кожною зміною.** Перед будь-якою зміною форми чи відповідей Claude зберігає копію на ваш комп'ютер у теку `Kobo-копії`. Копія містить форму й усі відповіді, але без фото. Для кожної форми лишаються 5 останніх копій.
- **Кожна форма поділена з організацією.** Для нової форми Claude питає, для якої вона організації, і сам ділиться нею з головним акаунтом з повними правами. Раз на день він перевіряє всі ваші форми і нагадує про неподілені. Без цього форми немає ні в нічному архіві, ні в Google Таблицях.
- **Видалення лише після вашого «так».** Спершу Claude показує, що саме зникне.

## Що потрібно

1. **Claude Code**: застосунок, термінал або розширення VS Code.
2. **Особистий акаунт** на eu.kobotoolbox.org. Не головний акаунт організації: ним працювати не можна.
3. **Python 3.9 або новіший.** Якщо Python немає, Claude підкаже, як його поставити.
   - **Mac:** у Терміналі виконайте `xcode-select --install` або встановіть Python з python.org.
   - **Windows:** встановіть Python з [python.org](https://www.python.org/downloads/) і поставте галочку «Add python.exe to PATH».

## Встановлення (один раз)

У Claude Code введіть по черзі:

```
/plugin marketplace add alexshap2002/kobo-skill
/plugin install kobo@kobo-skill
```

Потім перезапустіть Claude Code.

**Щоб оновлення приходили самі:** `/plugin` → вкладка **Marketplaces** → **kobo-skill** → **Enable auto-update**.

## Перший запуск

Напишіть Claude: **«Підключи мій Kobo»**. Він попросить API-ключ. Щоб його взяти:

1. Увійдіть на eu.kobotoolbox.org.
2. Відкрийте **Account Settings → Security → API Key → Display**.
3. Скопіюйте ключ і вставте його в чат.

Claude збереже ключ у файл на вашому комп'ютері і більше ніколи його не показуватиме.

## Що можна просити

- «Покажи мої форми».
- «Зроби форму реєстрації учасників тренінгу: ім'я, телефон, область, вік, згода на обробку даних».
- «Додай у форму "Моніторинг" питання про кількість дітей і розгорни».
- «Вивантаж відповіді форми "Моніторинг" в Excel».
- «Зроби дашборд по області й віку за жовтень».
- «У записах 12 і 15 місто має бути Львів».
- «Дай Петрові доступ на перегляд форми "Моніторинг"».
- «Поверни форму до вчорашньої копії».

## Якщо щось пішло не так

- **Невдала зміна форми.** Попросіть Claude повернути форму до копії.
- **Видалили не ті відповіді.** Їх може повернути адміністратор із копії чи центрального архіву. Фото не повертаються.
- **Видалили форму.** Вона 7 днів лежить у кошику Kobo. Пишіть адміністратору одразу.

## Для адміністратора

- Скіл лежить у `plugins/kobo/skills/kobo/` (`SKILL.md` і довідки в `references/`).
- Усі звернення до Kobo йдуть через `scripts/kobo.py`. Це Python лише зі стандартною бібліотекою, тож правила виконуються в коді, а не тільки в інструкціях.
- Щоденну перевірку на початку сесії робить `plugins/kobo/hooks/`.
- Ключ зберігається у `~/.kobo/token` з правами 0600. Копії лежать у `~/Kobo-копії/<форма>__<uid>/<дата-час>/`.
- Тести працюють на фейковому Kobo: `python3 -m unittest discover -s tests`. CI ганяє їх на Linux, Mac і Windows.

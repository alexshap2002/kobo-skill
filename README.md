# Kobo для Claude

Плагін для працівників **«Будь вільний»** і **«Є добро»**. З ним Claude працює з вашим акаунтом на
[eu.kobotoolbox.org](https://eu.kobotoolbox.org) звичайною мовою:

- створює й змінює форми;
- розгортає форми;
- вивантажує відповіді в Excel;
- робить звіти й дашборди;
- виправляє значення у відповідях;
- дає доступ колегам.

Плагін — це інструкція для Claude. Окремо нічого встановлювати не треба.

## Що потрібно

1. **Застосунок Claude** на комп'ютері (Mac або Windows).
2. **Особистий акаунт** на eu.kobotoolbox.org. Головні акаунти організацій для роботи не підходять.

## Встановлення (один раз)

У застосунку Claude відкрийте налаштування плагінів (**Customize → Plugins**). Додайте джерело
`alexshap2002/kobo-skill` і встановіть плагін **kobo**.

Якщо адміністратор додав плагін для всієї організації, нічого робити не треба: він уже є.

## Перший запуск

1. Виберіть у Claude теку для роботи, наприклад «Kobo» в Документах.
2. Напишіть: **«Підключи мій Kobo»** або одразу своє прохання.
3. Claude попросить API-ключ і пояснить, де його взяти: eu.kobotoolbox.org → свій значок угорі праворуч →
   **Account Settings → Security → API Key → Display**. Скопіюйте ключ і вставте в чат.

Claude збереже ключ у файл `kobo-ключ.txt` у вашій теці й більше його не питатиме. Не видаляйте цей файл і
працюйте з Kobo в тій самій теці.

## Що можна просити

- «Покажи мої форми».
- «Зроби форму реєстрації учасників тренінгу: ім'я, телефон, область, вік, згода на обробку даних».
- «Додай у форму "Моніторинг" питання про кількість дітей і розгорни».
- «Вивантаж відповіді форми "Моніторинг" в Excel».
- «Зроби дашборд по області й віку за жовтень».
- «У записах 12 і 15 місто має бути Львів».
- «Дай Петрові доступ на перегляд форми "Моніторинг"».
- «Поверни форму до попередньої версії».

## Що Claude перепитає

- **Перед видаленням** форми, відповідей чи чийогось доступу Claude скаже, що саме зникне, і спитає «Ви
  впевнені?».
- **Для нової форми** Claude спитає, для якої вона організації, і сам поділиться нею з головним акаунтом
  організації. Тоді форма потрапить у нічний архів і в Google Таблицю організації.
- **На початку кожної розмови про Kobo** Claude перевірить ваші форми. Якщо якусь ще не передано
  організації, він назве її, спитає, для якої вона організації, і поділиться.
- **Перед зміною питань, на які вже є відповіді,** Claude попередить, що старі відповіді можуть відірватися
  від форми.

## Якщо щось пішло не так

- **Невдала зміна форми.** Попросіть Claude повернути попередню версію.
- **Видалили не ті відповіді.** Їх може повернути адміністратор з нічного архіву. Фото не повертаються.
- **Видалили форму.** Вона 7 днів лежить у кошику Kobo. Пишіть адміністратору одразу.

## Для адміністратора

- **Що в плагіні.** Скіл лежить у `plugins/kobo/skills/kobo/`: `SKILL.md` і довідки в `references/`.
  Програм, скриптів і хуків немає.
- **Як Claude працює з Kobo.** Запити йдуть з комп'ютера працівника через сторінку eu.kobotoolbox.org у
  браузері, з ключем працівника. Помічник для цього лежить у `references/api.md`, розділ 1. Тому
  налаштування мережі в Claude не потрібні: Cowork виконує код у хмарі, а звідти Kobo може бути недоступний.
- **Ключ** лежить у `kobo-ключ.txt` у робочій теці працівника.
- **Тести.** `python3 -m unittest discover -s tests`. Вони запускають помічник з `api.md` у Node проти
  фейкового Kobo і перевіряють довідки.
- **Оновлення.** Номера версії в `plugin.json` немає навмисно. Кожен push до `main` доходить до всіх як
  оновлення.

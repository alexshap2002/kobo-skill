# Коли щось не працює

Працівнику кажи, що сталося і що робити далі, простими словами. Як ти працюєш, не пояснюй.

| Що бачиш | Що робити |
|---|---|
| `kobo.connect` → «ключ не підійшов» | Ключ змінили чи видалили, або він з іншого сервера (kf.kobotoolbox.org, старий український). Попроси новий з eu.kobotoolbox.org (SKILL.md, «Ключ») і перезапиши `kobo-ключ.txt`. |
| `kobo.connect` → «головний акаунт організації» | Таким ключем не працюють. Потрібен ключ особистого акаунта; якщо його нема, хай працівник звернеться до адміністратора. |
| `kobo.connect` → «Kobo не відповідає», статуси 5xx | Kobo тимчасово не працює. Скажи: «Kobo зараз не відповідає, спробую трохи згодом». Повтори за кілька хвилин. |
| `kobo is not defined` | Сторінку перезавантажили чи відкрили іншу. Знову виконай помічник і `kobo.connect`. |
| 403 на чужу форму | Працівнику дали лише частину прав. Власник форми може дати більше. |
| 404 | Неправильний код форми чи номер запису, або вже видалено. Перевір у списку форм. |
| 400 на відповіді форми | Форму ще не розгортали, тож відповідей у неї немає. |
| 400 при створенні чи зміні форми | Прочитай, що саме сказав Kobo, виправ опис форми (`forms.md`) і спробуй ще раз. |
| `kobo.share` → `ok: false` | Повтори один раз. Якщо знову — скажи працівнику, що форму не вдалося поділити з організацією, і дай контакт адміністратора. |
| Помилка зв'язку посеред зміни | Спершу перевір, чи зміна вже відбулася, і лише тоді повторюй. |

## Як повернути втрачене

| Що сталося | Як повернути |
|---|---|
| Невдало змінили форму | Поверни попередню версію (`api.md`, розділ 4) і розгорни. |
| Видалили чи зіпсували відповіді | Kobo їх не повертає. Адміністратор може повернути їх з нічного архіву, якщо форма поділена з організацією. Фото не повертаються. |
| Видалили форму | 7 днів вона в кошику Kobo. Одразу до адміністратора: він може повернути її разом із фото через підтримку Kobo. |
| Форма зникла з Google Таблиці | Перевір, чи форма поділена з організацією з усіма правами і чи розгорнута вона. |
| Збирачі не бачать нової версії | Форму розгорнули? У KoboCollect треба оновити форму («Get Blank Form»). |

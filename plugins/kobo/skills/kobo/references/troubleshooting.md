# Коли щось не працює

Помічник пояснює кожну помилку звичайними словами. Перекажи пояснення працівнику і запропонуй наступний
крок.

| Що пише помічник | Що робити |
|---|---|
| «Kobo ще не налаштовано» | Підключення з SKILL.md: попроси ключ, `setup`. |
| «Kobo не прийняв ключ» | Ключ змінили або видалили. Попроси новий (Account Settings → Security → API Key) і зроби `setup`. |
| «Ключ не підійшов до eu.kobotoolbox.org» | Найчастіше це ключ з kf.kobotoolbox.org або старого сервера. Потрібен саме з eu. |
| «ключ головного акаунта» | Головними акаунтами не працюють. Потрібен особистий акаунт працівника; якщо його нема, хай звернеться до адміністратора. |
| «немає на це прав» | Форма чужа і з працівником поділилися лише частково. Власник форми може дати більше прав (`share-user … --role edit`). |
| «Kobo не знайшов цю форму чи запис» | Неправильний uid чи ID, або вже видалено. Перевір через `forms` / `export`. |
| «Сервер Kobo зараз не відповідає» / «Немає зв'язку» | Спробуй за кілька хвилин; перевір інтернет. |
| «Форму не збережено, бо в ній є помилки» | Виправ перелічене в описі форми (див. `references/forms.md`). |
| «Зміну не зроблено, бо вона зачіпає питання…» | Правило Р5: краще додати нове питання; `--force` лише після «так» працівника. |
| «Kobo відхилив запит (…)» | Прочитай, що саме сказав Kobo, і поясни простими словами. Якщо незрозуміло, звернися до адміністратора. |
| «потрібен Python 3.9» | Допоможи встановити Python (Mac: `xcode-select --install` або python.org; Windows: python.org з галочкою «Add python.exe to PATH»), потім перезапуск Claude Code. |
| «Не вдалося встановити захищене з'єднання» | Проблема з сертифікатами на комп'ютері. Mac з Python з python.org: запустити «Install Certificates.command» у теці Python. Інакше — до адміністратора. |

## Як повернути втрачене

| Що сталося | Як повернути |
|---|---|
| Невдало змінили форму | `restore-form <uid> --backup latest` (або обрати копію з `backups <uid>`), розгорнути. |
| Видалили чи зіпсували відповіді | Локальна копія є в `~/Kobo-копії/…` (без фото). Відповіді назад у Kobo повертає адміністратор із копії чи центрального архіву. |
| Видалили форму | 7 днів вона в кошику Kobo. Одразу до адміністратора: він може повернути її разом із фото через підтримку Kobo. |
| Форма зникла з Google Таблиці | Перевір `check-sharing`: чи поділена форма з організацією, і чи розгорнута вона. |
| Збирачі не бачать нової версії | Форму розгорнули? У KoboCollect треба оновити форму («Get Blank Form»). |
